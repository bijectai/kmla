# Human-approved invariant claims

Add only claims you endorse, parameterized over the implementation so each can
be instantiated with the oracle or a model output. Oracle proofs belong in
`invariants/proofs/` at the repository root.

Candidate claims will be proposed in the root `invariants/candidates/` directory
for your review and promotion here. The executable declaration contract remains
pending; see `docs/HANDOFF.md` at the repository root. No signed claims are
included in this scaffold.
